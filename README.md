# Поток

Совместный менеджер задач и проектов на русском языке.

## Возможности

- Рабочие пространства, приглашения по ссылке, роли: владелец, администратор, участник.
- Проекты: открытые и закрытые, роли в проекте (владелец, редактор, наблюдатель), архив, шаблоны разделов.
- Задачи: исполнитель, сроки (дата начала и срок), приоритет, метки, описание, подзадачи, файлы до 10 МБ.
- Зависимости между задачами («ждёт задачу»), защита от замкнутых цепочек.
- Повторяющиеся задачи: каждый день, по будням, каждую неделю, раз в две недели, каждый месяц, каждый год.
- Виды проекта: список, доска (канбан), календарь, график (диаграмма Ганта). Везде работает перетаскивание.
- «Мои задачи» по срокам, «Входящие» с уведомлениями, комментарии с @упоминаниями, история изменений.
- Поиск по задачам, проектам и людям, фильтры.
- Изменения коллег видны сразу, без перезагрузки страницы.
- Светлая и тёмная тема, версия для телефона.

## Технологии

Node.js 20+, Express, Socket.IO, PostgreSQL; интерфейс на React, Vite, Tailwind CSS.

## Запуск на Render (бесплатно)

1. Зарегистрируйтесь на https://render.com через аккаунт GitHub.
2. Нажмите **New → Blueprint** и выберите этот репозиторий.
3. Нажмите **Apply**. Render сам создаст базу данных и сервер по файлу `render.yaml`.
4. Через 3–5 минут приложение будет доступно по адресу вида `https://potok-xxxx.onrender.com`.

## Локальный запуск

```bash
# нужна PostgreSQL; по умолчанию: postgres://app:app@localhost:5432/zadachi
npm install
npm run build
DATABASE_URL=postgres://user:pass@localhost:5432/potok JWT_SECRET=любая-длинная-строка npm start
```

Откройте http://localhost:3000.

## Переменные окружения

| Переменная      | Назначение                                                                 |
|-----------------|----------------------------------------------------------------------------|
| `DATABASE_URL`  | Строка подключения к PostgreSQL                                            |
| `JWT_SECRET`    | Секрет для подписи сессий. Обязателен в продакшене                        |
| `DATABASE_SSL`  | `true`, если база требует SSL (например, Neon или Supabase)               |
| `PORT`          | Порт сервера, по умолчанию 3000                                            |
